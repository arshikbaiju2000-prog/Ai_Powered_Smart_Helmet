## ESP32-S3 Camera Firmware

Board: XIAO ESP32-S3 Sense  
Camera: OV3660  
Resolution: QXGA (2048×1536)  
Protocol: TCP socket image streaming

### Features
- High-resolution image capture
- Wi-Fi SoftAP
- JPEG streaming to Android app

### Build Notes
- PSRAM must be enabled
- ESP32 Arduino core ≥ 2.0.14
